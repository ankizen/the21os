## Corrections vs. the Original Research Report

1. **Meta Marketing API version is stale in the report.** The report assumed v25.0 default / v26.0 emerging. **v26.0 shipped 2026-07-29 and is current** as of today (2026-08-21); v25.0 is now one version back; v23.0 expired 2026-06-09. Build against v26.0.
2. **Advantage+ Shopping/App API restriction is now fully in force**, not a future date. The report's "extending to all versions by May 19 2026" has already happened — confirmed active for ~3 months. Our Meta module must hard-reject `create`/`update` calls for ASC/AAC campaign types regardless of API version, at the code layer (not left to Claude to avoid).
3. **`konquest-meta-ads-mcp`'s "215 tests passing" / full rollback story is materially overstated.** Direct inspection of `safety/rollback.py` shows it's an explicit "Phase v1.3 — skeleton with interfaces" stub. Downgraded from the report's FORK verdict to architecture-reference-only.
4. **`pipeboard-co/meta-ads-mcp` has an open, unaddressed security-scanner finding** (issue #69, score 0/100 across 35 tools) not mentioned in the report. Downgraded to copy-pattern-only, explicitly do not run as a dependency.
5. **The report's GA4 repo username `thsyedyahya` is wrong** — confirmed 404. Correct is `thesyedyahya/ga4-mcp`.
6. **Official Python MCP SDK has a breaking change in flight.** `mcp.server.fastmcp.FastMCP` (bundled in `modelcontextprotocol/python-sdk`) is what current templates use, but SDK v2.0 (beta since 2026-06-30, reportedly now the stable line for the 2026-07-28 protocol spec) **renames `FastMCP` to `MCPServer` and removes the old import path outright — no compatibility shim.** We'll pin the exact SDK version at Phase 1 setup time and write against whichever is genuinely latest-stable then; this is called out as an open verification item, not resolved by guesswork today.
7. **The MCP protocol spec itself has moved past what the report assumed.** 2026-07-28 superseded 2025-06-18: the core protocol is now stateless (no `initialize` handshake/session ID), with OAuth hardening (RFC 9207 issuer validation, Dynamic Client Registration → Client ID Metadata Documents). Transports are unchanged (stdio + Streamable HTTP only).
8. **`pawansingh3889/mcp-server-template` is archived** (2026-07-29) — not mentioned as a risk in the report. Dropped from consideration.
